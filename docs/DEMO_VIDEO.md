# JX Buddy：120秒产品录屏脚本

录制真实网页操作，展示同一名用户完成一项研究。使用单家公司、一个明确目标。录制前确认金融数据展示授权，折叠受限原始字段，不展示密钥或个人信息。

| 时间 | 产品操作 | 展示重点 |
|---|---|---|
| 0–15秒 | 新建研究，选择真实接入，输入贵州茅台2025年度利润核验目标 | 用户提出目标 |
| 15–30秒 | 查看任务计划和工具，点击确认 | 用户确认与执行边界 |
| 30–55秒 | 执行工具，展开轨迹和一条证据 | 扶摇真实调用、来源、时点、单位、口径 |
| 55–80秒 | 展示RSI自检与修订反馈 | 最多两轮检查一次修订；没有发现问题也如实展示 |
| 80–105秒 | 查看报告，点引用、展开局限，完成复核 | 事实/推断/不确定，结果可核验 |
| 105–120秒 | 展示检查点和Markdown导出 | 持久化与可交付成果 |

建议目标：核验贵州茅台2025年度利润和估值，区分财务报告期与最新快照时点；缺失字段标为不确定。

如展示iFinD，明确说明线上超时，演示跳过和数据缺口，不宣称成功。原始等待可剪短并标注“等待已剪辑”，保留同一任务连续逻辑；不拼接不同任务冒充一次运行。

成品60–180秒，建议1080p MP4，中文字幕或简短配音。使用系统录屏或OBS录产品窗口。先走查一次；新真实运行通常消耗3–5次模型请求，重录前查看累计预算。本文是脚本，视频尚未录制。
