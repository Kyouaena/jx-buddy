# AI 使用与验证记录

## 开发工具与参与

- 使用 Codex 读取题目附件、检索 GitHub／官方协议、制定架构、生成 TypeScript／React／CSS、测试与文档。
- 当前应用演示模式不调用模型。真实模式预留兼容 JSON 输出的模型接口，模型参与计划与报告，不负责身份验证、权限批准、数据库隔离和预算控制。
- 人类用户提供任务范围与交付要求；未记录尚未发生的人类代码修正或验收。

## 开发中识别与修正

1. Sites 源模板锁文件与新增 LangGraph 依赖不同步：同步 lockfile 后重新安装。
2. 类型检查发现 Cloudflare `Response.json()` 为 unknown、Node 测试 `.ts` import 配置缺失：补充响应类型和 `allowImportingTsExtensions`。
3. 明确区分构造数据演示与真实研究，避免将未接入的扶摇／iFinD 显示为已连接。
4. 历史恢复保留累计预算，避免回滚状态后重置消耗。
5. 在正式总结之前执行自动测试、类型检查、生产构建和本地 API 主链路验证；具体结果见 TESTING。

## 模型结果的验证责任

结构检查：plan 只使用已启用的工具；report 的每条事实／推断有已存在 E 引用；异常证据不能作为正常事实；基础正则拦截直接交易建议和确定性收益。原始证据与引用可由人类核查。

当前不具备全自动语义证据蕴含验证。真实模型与供应商未接入，不能把演示验证当成真实投研质量验证。
